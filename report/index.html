Decisions the group still needs to make

  • HELOC missing values. "Missing means it never happened" holds only for MSinceMostRecentDelq (95%). It fails for NetFractionInstallBurden (6%) and MSinceMostRecentInqexcl7days (54%), whose sentinel now means "unknown" and is frozen.
  • Training-data predictions. DiCE's KD-tree and FACE's graph label the training data without charging the budget. Counting them would cost DiCE 31k queries per instance on Adult.
  • COMPAS actionability. Strict actionability leaves no actionable feature (nothing can run); Guidotti's leaves one group. The runs use Guidotti's.
  • COMPAS accuracy rule. The plan reads accuracy above 0.65 as label leakage. Ours is 0.67 with no leaking column, matching Dressel and Farid (2018).
  • Wachter on Adult with the neural network reaches 1.00 against 0.50 in CARLA, with CARLA's stop rule and lambda schedule. The difference is the model and CARLA's timeout.
  • MOC still has no owner, and NS, NSLC and surprise are not in these runs yet.
Definitions and protocol

Success: share of instances with at least one valid counterfactual. Valid: the model predicts the favorable class.

Min distance: Guidotti distance (MAD-weighted L1 on numeric features plus mismatch share on categorical ones) of the closest valid counterfactual. Features changed: mean L0.

Diversity: mean pairwise distance among valid counterfactuals. Redundancy: changed features that can be reverted without losing validity (CARLA).

Budget: model queries counted by a wrapper around every model call, gradient steps included. Each budget is an independent run with the same search seed.

Fixes applied before these runs: DiCE's KD-tree initialisation no longer stalls in uncapped random sampling (COMPAS went from 0.0 to 0.9–1.0 success); FACE checks up to 500 projected candidates.
